# MergeMint Documentation

Design docs, guides and reference material for the MergeMint contracts,
backend, frontend and SDK.

New here? Start with [Getting started on testnet](getting-started.md), then
read the [glossary](glossary.md) for the terms used throughout these docs.

The published site is built from this folder with [mdBook](https://rust-lang.github.io/mdBook/).
To preview it locally, install `mdbook` and `mdbook-linkcheck`, then run
`mdbook serve` from the repository root.
